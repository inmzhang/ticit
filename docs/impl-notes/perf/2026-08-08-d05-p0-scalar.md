Diagnostic host: Intel Core i5-14600KF, P-core CPU 0, AVX2. Build:
`CARGO_PROFILE_RELEASE_DEBUG=1 cargo build --release --bin ticit_rate_bench`.

The two nondiagonal kernels compile to XMM arithmetic with a horizontal

scalar path intentionally preserves the C++ scalar evaluation order for
bit-exact validation.

## Retained change

Ported SymFT's one- and two-word register fast paths into
`xor_symbolic_bool_batch_into`. Two repeated runs measured 224,044.2 and
223,768.2 shots/s: about **+1.1%** over baseline. Tests cover one live word
with one- and two-word capacity, plus two live words. Post-change batch output
remained bit-exact on `d05_p0`, `d05_p1e-3`, `msc_d3`, and
`pure_surface_d7`.

On the EPYC 9254 reference server, the same change improved ticit from
140,446.8 to 169,400.4 and 169,261.8 shots/s (**+20.6%**). A fresh native
SymFT run measured 189,692 shots/s, leaving ticit 10.7% behind on this case.
The post-change source passes `cargo test --all-targets` on that host.

## Rejected changes

- Unchecked indexing in the two nondiagonal kernels: 221,355.7 shots/s
  (-0.05%, noise). Removed; it did not justify an unsafe boundary.
- Forced inlining of symbol-assignment checks: 209,914.2 and 217,085.6
  shots/s. Removed as a regression.
